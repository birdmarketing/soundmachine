# URL map: sound-machine.com → new site

The new site keeps the live site's exact URL structure: lowercase paths with **no trailing slash** for marketing pages (`/how-it-works`, `/licensing/united-states`) and WordPress-style dated URLs **with** a trailing slash under `/blog/`.

The full inventory is in [`url-inventory.csv`](url-inventory.csv): 1,064 URLs, with the type and phase-1 status of each. It was built from:

- the live XML sitemap at `https://sound-machine.com/resources/docs/sitemap.xml`. It is capped at 1,000 entries and is generated by pro-sitemaps.
- the `hreflang="es"` alternates declared in that sitemap.
- the WordPress REST API (`/blog/wp-json/wp/v2/posts`), which lists all **194** blog posts. Some of them are missing from the capped sitemap.

Captured 6 November 2026.

### Blog (WordPress, under `/blog/`)

| Pattern | Count | Example |
| --- | --- | --- |
| `/blog/` | 1 | |
| `/blog/YYYY/MM/DD/slug/` | 194 posts | `/blog/2022/05/28/ascap-vs-bmi/` |
| `/blog/category/slug/` | 8 categories | `/blog/category/licensing/` |
| `/blog/tag/slug/` | 285 tags | `/blog/tag/ascap/` |
| `/blog/author/slug/` | 5 authors | `/blog/author/aaron/` |
| `…/feed/`, `?lang=es` | feeds and Spanish variants | |

Recommendation: keep WordPress serving `/blog/*` behind the same domain, either through a Worker route that proxies to the WordPress origin or by moving the WordPress install. Alternatively, migrate the posts into an Astro content collection; the REST API is open, so a migration script is simple. The new site already links to existing posts at their live URLs (Research → Insight library).
